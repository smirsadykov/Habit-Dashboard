        Sync via GitHub

        Optional. Leave this blank and your progress never leaves this device.

        Filling it in shares one data/daydesk.json between every device that holds the repository and a token. Use a fine-grained token limited to that single repository with Contents: Read and write and nothing else; it is kept in this browser and never sent anywhere else.
